# Telangana Tourism Dashboard 🏞️📊

This project presents a **Power BI dashboard** that visualizes tourism trends across various districts and attractions in **Telangana**, India. It offers insights into visitor demographics, attraction popularity, and tourism patterns using clean and interactive visuals.

---

## 📁 Project Files

- `Telangana Tourism.pbix`: The Power BI dashboard file.
- `Tourist_individual.xlsx`: Source dataset containing attraction-wise tourism data.
- `insights.txt` *(optional)*: Key observations drawn from the dashboard.
- `README.md`: Project overview and usage guide.

---

## 📊 Dashboard Features

The Power BI dashboard includes:

- **Bar Chart**: Top tourist attractions by total visitors.
- **Line Chart**: Comparison of domestic vs international visitors.
- **Donut Chart**: Distribution of visitors by type of attraction (Historical, Natural, Entertainment).
- **Map Visual**: Geographical spread of tourism hotspots.
- **Slicers**: Filter by district, year, or attraction type.
- **KPI Cards**: Quick stats on total visitors, average ratings, and number of reviews.
- **Table View**: Detailed breakdown of all attractions.

---

## 🗂 Dataset Overview

**File**: `Tourist_individual.xlsx`  
**Columns include**:
- `Attraction_name`
- `District_name`
- `Total_visitors`
- `Domestic_visitors`
- `International_visitors`
- `Type` (Historical, Natural, Entertainment)
- `Visiting_year`
- `Rating_avg`
- `Number_of_Reviews`

---

## 🔍 Key Insights

1. **Charminar** had the highest footfall with over 1.28 million visitors.
2. Tourism is **dominated by domestic visitors** (>85% across all attractions).
3. **Historical sites** attract the most tourists, followed by entertainment venues like Ramoji Film City.
4. Tourist activity **peaks in the winter months**, especially December.
